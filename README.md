# LexiCura

LexiCura is a source-code analyzer with a browser-based interface and an Expo mobile app.

Review detected issues and apply suggested corrections line by line. When more than two issues are found, the browser and mobile apps also offer a one-pass correction for the entire source, followed by a fresh analysis.

## Browser app

Open `index.html` in a browser.

## Mobile app

See [`mobile/README.md`](mobile/README.md) for Expo Go setup and run instructions.
